# 工作札記（按日期）

> 作者交代（2026-11-03）：**往後按日期留札記**，多留點東西給後進。
> 這裡是「那一天發生了什麼、為什麼、留下什麼數字與待辦」，不是規格也不是教學；
> 規格看 [`../addressing.md`](../addressing.md)，原則看 [`../insights.md`](../insights.md)。

## 怎麼寫

- 一天一個檔：`YYYY-MM-DD.md`（同一天延續就往下加，不另開檔）。
- 每次工作結束留一則，至少寫：
  1. **做了什麼**（改了哪些資料／程式／文件）。
  2. **為什麼**（誰的決定、依據是什麼）。
  3. **數字**（行數、段數、比對結果、檔案大小…能重跑的都要能重跑）。
  4. **沒做完／留給後人**（含已知瑕疵與風險）。
- 引用作者的話用「作者：…」；自己的推論要标明是推論。
- 不要把密碼、token、主機指紋寫進來。
