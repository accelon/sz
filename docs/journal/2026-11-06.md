# 2026-11-06

## 一、cs 的詞譜標籤 `<詞>` → `<辭>`

**為什麼**：作者 2026-11-06 指示，cs 的「詞譜」標籤由 `<詞 b="…" j="…">` 改成
`<辭 b="…" j="…">`；詞典（cyd／hydzd…）的 `<詞>` 詞頭不動。這樣閱讀器與建置端不必靠
「有沒有 b／j」去猜這個 `<詞>` 是詞譜還是詞頭；舊版閱讀器仍讀舊 `<詞>`，新版閱讀器兩種都認
（母區 `render_accelon3.ts` 的 `name === '詞' || '_' + 詞 || '辭' …`；`ts/test/dict-annotations.test.ts`
已有一條「cs 新詞譜 `<辭 b/j>` 仍走 word」）。

**怎麼做**：

1. **來源／建置腳本**（不是只手改 out 中間檔）：
   - `src/provident-text.ts`：產出的詞譜標籤直接改成 `<辭>`（含 `f=` 的壞詞譜 fallback）。
   - `src/cs2accelon.ts`：驗收用的 `<詞 `／`<詞 f=`／`<詞 b="…" j="…">` 三條 regex 與註解同步改 `<辭>`。
   - `src/cs-split-exp.ts`、`src/cs-digit-exp.ts`、`src/decomp/*`（sources／preview／sandhi-code／
     markup-vs-pwa／sandhi-codebook.py／unresolved-words.py）：解析 `data/cs` 的 regex 改成
     `<[詞辭] …>`，舊備份與新資料都吃；`preview.ts` 產生預覽時改產 `<辭>`。
   - `src/cs-rename-tag.ts`（新，可重跑）：把 `data/cs/*.xml` 的 `<詞`／`</詞>` 就地改成
     `<辭`／`</辭>`。只認標籤名（`</?詞` 後面接空白或 `>`），正文的「詞」字不動；每個檔都驗
     「去掉標籤後文字一字不差、長度不變」才寫回。
2. **重建**：`bun run src/pack.ts cs`（73.5 s，全文索引）、`bun run src/build-cs-lex.ts`。
   成品只放 `accelon26/`，**沒有上傳**（依作者 2026-11-06：adb 由母區統一部署）。
3. **文件**：`README.md`、`docs/steps.md` §1.1（加一段改名說明）、`docs/canon-status.md`、
   `docs/lex-pane.md` 的「目前格式」改成 `<辭>`；`version-log.md` 加兩列（cs、cs-lex）。

**數字**：

  `<辭>` **437,557**（屬性形式：`b+j` 437,546、`f` 11）。163 檔本來就沒有詞譜。
- `cs.adb`：**124,965,051 bytes**（sha256 前 12 `48253dfa294e`，buildTime 2026-11-06T04:39:25Z）。
  行 **1,028,311**、字元 **116,146,056**、tokens **841,154**，三項與改名前完全相同
  （只有標籤名換字，正文／詞序／VA 都沒動）。`<詞 0`、`<辭 437,557`；
  `tags` 只剩 `辭`／`/辭`（原本 `詞`／`/詞`），`attributes`＝`辭.b`／`辭.f`／`辭.j`。
  用閱讀器 `Accelon3Renderer` 實際畫一行：12 個 `.word` span、`data-b="tjVjnIIy|kmVmM" data-j="0"`。
- `cs-lex.adb`：**2,826,760 bytes**（sha256 前 12 `50bc371ff6e3`，buildTime 2026-11-06T04:39:36Z）。
  `<辭>` **39,479**（原 `<詞>` 39,479；DN1 12,530＋DN2 13,937＋DN3 13,012），`<詞>` 0；
  2,479 詞條、22,527 行、1,360 段不變。

- 作者說 cs.adb「約 135,088 個 `<詞>`」，實測**標籤 437,557 個**；135,088 正好是
  **含詞譜的行數**（`grep -c '<詞'` 的算法：一個 adb 行是一句，常有 2–5 個詞譜）。
  同理 cs-lex 的「13,250」是 dn1–3 含詞譜的行數（3,621＋4,892＋4,737），標籤是 39,479 個。
  本次驗收以「改名後 `<辭>` 標籤數＝改名前的 `<詞>` 標籤數」為準，兩邊都對得上。
