## 3. 建置流程（暫定）

```text
① 取源（原始檔放 data/，唯讀；大檔與 zip 不進版控）

③ 補資料（缺字、術語、頁碼、平行對照；外部檔，不改原始檔）
④ 連結（<聯>、<嵌>、j；patch 最後跑）
⑤ 打包（母區 ts/src/adbauthor.ts 的 authorAdb）
⑥ 驗證＋記帳（母區 adb-version-log.md、deploy/adb-notes.json）
```
