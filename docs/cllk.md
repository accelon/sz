## 2. html → Accelon XML

轉檔腳本：`src/cllk2accelon.ts`（直接讀 html，不經過 `.off`）。

| html | Accelon XML | 說明 |
|---|---|---|
| `<center class=n>…` | — | 版頭、南無、`____` 丟掉 |
| `<center>N. …สูตร</center>` | `<塊 id="m51">…</塊>` | 長部／中部：一經＝一塊；泰數字換算成跨庫編號（mn2 從 m51、mn3 從 m101） |
| `<center>N. …สังยุต</center>` | `<塊 id="s12">…</塊>` | 相應部：一相應＝一塊（sn2 從 s12、sn3 從 s22…） |
| `<center>อังคุตตริกาย …นิบาต</center>` | `<塊 id="a2">…</塊>` | 增支部：一集＝一塊（塊名用 profiles 的簡名） |
| `<center>…วรรค／…ปัณณาสก์</center>` | `<節>…</節>` | 品／五十經編 |
| `<center>其他標題</center>` | `<項>…</項>` | 經名、小節（長部的小節也走這裡） |
| `[๓]<a name=3></a>` | `<段 n="3"/>` | 段號；`<a name>` 給阿拉伯數字 |
| `<sup>๑-</sup>` | `<註 n="1" pg="m1.1"/>` | 註號（每頁重編，所以帶 `pg`） |
| `<small>@<sup>๑</sup> 注文</small>` | `<釋 n="1" pg="m1.1">…</釋>` | 放 `<書>-fn.xml`；續行接到同一條；**範圍號** `<sup>๑-๔</sup>` 會展開成 4 條 |
| `<small class=foot2>{ที่มา … หน้า : ๑๙๗}</small>` | `<pb n="197"/>` | 原書頁碼，接在該頁最後一行行尾 |
| `<p class=reftop>` 每頁書眉 | — | 丟掉；但**相應部拿它判斷塊邊界**（有幾相的標題頁在來源裡缺了） |

**頁塊與去重**：網站每個 siri 檔在頁界切開，相鄰兩檔常重複一頁（後檔是前檔的子集）。
轉檔按「卷＋頁碼」去重，只留第一次出現（實測 349 個重複頁全部是「後 ⊂ 前」）。
每個 siri 檔尾的引用區（「เนื้อความ…」＋網址）截到最後一個頁腳為止。

**沒有 `<頁>` 標籤**：定位字串就是 `塊.段`（`m51.17`），閱讀器 `anchorVa()` 會退回查
`attributes/塊.id` ＋ `attributes/段.n`。

**目錄名稱**：`塊` 的內容是「`(經號) 經名`」，例如 `(14) มหาปทานสูตร`、`(22) ขันธสังยุต`、
`(2) ทุกนิบาต`。經號用跨庫編號（`d14`／`m51`／`s22`／`a2` 的那個數字），不是泰譯的冊內號，
所以和 `cs-mm`、`sc` 的塊號一致；`<節>`／`<項>` 是正文裡的品與小節，不進目錄樹。

閱讀器的目錄標籤原本只取 24 個字（`vapa.ts` 的 `nodeLabel`），泰文名字常超過，會被截成半個詞（`(151) ปิณฑปาตปาริสุทธิสู`）。2026-11-02 把上限改成 **60 字**（`LABEL_MAX`），`D:\accelon3\accelon26.html` 已重建；桌面版 exe 要等下一次建置才會生效。

## 3. 段號對得上嗎（重點）

泰譯 MCU 的 `[N]` 是「一冊之內連續編號」（增支部是「一集之內」），和 `cs-mm` 的 `^n`
同一個規則。實測：

| 區 | 結果 |
|---|---|
| 長部 | **完全相同**（dn1 1–559、dn2 1–441、dn3 1–360；補抓 3 經後逐段吻合） |
| 中部 | 段數接近（mn1 508／500、mn2 477／486、mn3 460／463）；差的是泰譯省略的經與少數段號落點不同 |
| 相應部 | 最大段號和緬譯相同（sn1 271、sn3 716、sn5 1201），但泰譯把「等等」的經省略、不編號，所以錨點較少（sn1 251、sn5 471…） |
| 增支部 | 最大段號大多相同（an1 1..611、an2 1..231、an3 1..156…），但泰譯只在起點給錨點，範圍內的號沒有錨點 |

結論：**長部可以逐段跨庫跳**；中部／相應部／增支部可以跳有錨點的段，沒錨點的是
來源省略（泰譯的經文本身也省略），不是轉檔漏掉——正文逐字比對（泰文字母數）全部相符。

## 6. 已知限制

1. **中部／相應部的段號不是每個都對得上緬譯**（見 §3）：泰譯省略的經不編號。
2. **註／釋 有零星對不上**（全庫約二十條）：來源有些注文排到下一頁，或同一頁同號重複。
   轉檔用「這一頁的註號表＋上一頁」配 `pg`，報告的「註↛釋」欄會列出來。
3. **sn3 有一個重複段**（第 181 段出現兩次）：補抓的 17-333 與 17-332 在頁界各有一份，
   內容略有差異所以沒被去重。只影響一頁，不影響段號。
4. **標題只有 `<節>`／`<項>` 兩層**，沒有再做「章」；目錄用「區→書→塊」三層。
